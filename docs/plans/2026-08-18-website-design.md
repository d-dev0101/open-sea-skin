# Open Sea 官网设计

## 产品叙事

官网采用“潮汐控制室”而不是传统插件落地页。用户进入首页后先看到真正运行的
WebGPU 海洋，以及一层可辨认的 DeepSeek Harness 玻璃界面；波浪、日光和界面
通透度控制始终在首屏可见。首页的核心承诺是：**不是观看演示，而是亲手试用皮肤**。
视觉语言延续 Open Sea 的深海蓝、冷青高光和夕阳珊瑚色，并用海图刻度、坐标、
细线和不对称排版强化“海洋观测仪器”的识别度，避免做成通用 SaaS 模板。

## 页面结构

首屏包含精简导航、产品标题、安装入口、真实 Harness 模拟壳和控制台。三组预设
（平静、夕阳、高海况）用于快速展示极端状态，三个滑杆提供连续调节；默认界面
通透度为 64%，让海面成为第一视觉焦点。首屏之后依次是技术与隐私证据、四张真实
Harness 动图、三种安装方式、兼容与性能说明、开源入口。中文默认，英文可一键
切换。移动端保留真实海洋和控制功能，简化 Harness 三栏壳，避免把互动降级成图片。

## 技术与降级

官网是 GitHub Pages 可直接托管的纯静态站点，不使用分析脚本、Cookie 或远程代码。
现有 `shared/ocean.js`、本地 three.js/TSL 和字体在构建时复制进 Pages 产物；海洋运行
在同源 iframe 中，父页面只通过受来源检查的 `postMessage` 更新海况与日光。通透度
仅作用于官网模拟界面。WebGPU 不可用时保留完整内容、渐变海面和安装入口，并明确
提示用新版 Chrome/Edge 查看实时效果。浏览器验收覆盖滑杆与预设、双语、复制命令、
窄屏布局、无横向溢出、控制台错误和资源 404；发布后再对 GitHub Pages URL 重跑
关键路径并把该 URL 写入仓库 Homepage 字段。
