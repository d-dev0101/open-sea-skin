# Contributing

Issues and focused pull requests are welcome. Please describe which install
path is affected: DSH bundle, Harness source integration, static installer, or
Chrome/Edge extension.

## Development

Use Node.js 20 or newer, then install dependencies and run the full local gate:

```sh
npm ci
npm run build
npm run check
npm run test:browser
```

Edit the canonical renderer and host controller in `shared/`. Run
`npm run build` after changing them; generated copies under the install paths
must stay byte-for-byte synchronized.

For the root DSH bundle, `plugin/client.js` is generated by
`scripts/build-dsh-bundle.mjs`, while `plugin/index.js` owns the local static
asset route. New network access, remote code, analytics, or broader browser
permissions are out of scope unless they are separately proposed and justified.

## Visual changes

Keep controls keyboard accessible and preserve `prefers-reduced-motion`.
Gallery updates must come from a running DeepSeek Harness instance, use 40%
glass opacity, and include both light and dark modes. Run `npm run capture` and
visually review every generated file before committing it.

## Pull requests

Keep changes scoped, explain user-visible behavior, list the checks you ran,
and update `CHANGELOG.md` for notable changes. Do not include local Harness
profiles, API keys, workspace contents, or Playwright output directories.
